# Mythos Garden

An Angular world-building toy for inventing tiny imaginary ecosystems. Choose a landscape, tune its climate, and invite species whose roles nudge the ecosystem pulse. The illustrated habitat responds as the world changes, and the builder saves your garden in local browser storage.

## Start the app

1. Install Node.js 20.19+ or 22.12+.
2. Double-click `Start-MythosGarden.bat`. The first launch downloads the Angular packages, then starts the app.
3. Open the local URL shown in the terminal (usually `http://localhost:4200`).

Or open a terminal in this folder and run `npm.cmd install`, then `npm.cmd start`.

## Build

```sh
npm run build
```

## What's inside

- Three distinct biomes with responsive illustrated scenery
- Adjustable moisture, warmth, and starlight controls
- Toggleable species and a live ecosystem health score
- Save and restore a garden locally; no account, API, or external service
- Responsive layout for desktop and mobile

Made with Angular standalone components and plain CSS. The `dist/` and `node_modules/` folders are generated locally and are excluded from Git.
